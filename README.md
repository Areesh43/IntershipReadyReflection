# Intership Ready Reflection

	During the first half of the spring semester, I enrolled in CIS 3590, Internship-Ready Software Development. I decided to enroll in this course to prepare myself for a future internship. My intent for this course was to improve both my technical skills and my soft skills. Most of my experience came from completing assignments and projects within my other classes, which meant I was lacking experience outside of the classroom. 

	Throughout the course, I was given the opportunity to work on several assignments that would help me improve my technical and soft skills for a future internship. An example of some of the assignments given to me was creating a GitHub profile to store and manage my projects, a Streamlit data app that uses an API to retrieve data when requested, using Flask for the first time for web application development, and creating an AI chatbot. Outside of those assignments, I also worked with some of my peers on a project given to us by a company. These projects helped me gain practical experience with tools and concepts that are widely used in software development today.

	I learned a bunch of technical skills through multiple projects. The first project that was given to us to work on was creating a GitHub profile. Creating a profile has helped me learn to practice project management, use version control for software development, and figure out the advantages as well as challenges of open-source software development. The second project assigned was a Streamlit data app. This assignment taught me how APIs work and how they can be used to retrieve data when requested. I was intrigued by how a simple key being called upon can help you gain access to an entire database of a website.

	The third project was creating a Flask website, which was my first time using the framework. Flask helped me understand how to structure web applications and how the web application interacts with APIs. It has also reinforced more on using open source tools and how to integrate them with different technologies.

	For the final project, I built an AI chatbot that answers questions about a document uploaded by the user. The project expanded my knowledge of APIs by using the Google Gemini API to help generate the responses. I also created functions to process any documents uploaded by the user and then allowed the chatbot to answer questions about the documents provided. Working on this project has helped me understand how to create AI tools and how they can be integrated into applications.

	Throughout the individual projects given, I also worked on a group project where our task was to create an AI Image generator for Boxlang. The project helped me improve my soft skills, with emphasis on adaptability and teamwork. Due to everyone having different ideas on how to approach the assignment, it was important to communicate with everyone to have a clear idea of how to solve the problem. Overall, the whole course has helped me expand both my technical and soft skills through hands-on experience with different projects.

	The course has helped me refine multiple real-world skills, such as teamwork and communication skills, while diving deeper into my knowledge of Python, the standard programming language most tech companies use nowadays. Gaining more experience with Python can help me demonstrate my technical skills to potential employers. With the help of the group project and taking a mock interview meeting with one of the tech talent peer advisors, the improvement in my communication skills can help me talk in an interview properly while delivering answers to the questions given, creating more confidence in myself. The course has helped improve my resume and LinkedIn, making it easier to land interviews for any future internships. This course has helped me build both technical and professional skills, which will be really useful when finding internships.

	The most valuable thing that I have learned from this course is that my knowledge of Python has expanded, as well as how to use APIs more commonly. The course has also helped me develop more confidence in how to properly communicate with someone, whether it would be a teammate or an interviewer. I feel like I still have room for improvement, but this course gave me a great opportunity to improve these skills.
